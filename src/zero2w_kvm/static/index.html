입력 컨트롤

제어 해제·입력 중지: Ctrl+Alt+Shift를 함께 누르세요. Esc는 대상 컴퓨터에 전달합니다. Esc·Alt+Tab 등은 전체 화면에서 브라우저의 키보드 잠금을 허용해야 전달됩니다. Fn 등 OS가 브라우저에 전달하지 않는 키는 지원되지 않습니다.

대상 Windows 도우미 연결 대기

최초 한 번, 아래 도우미를 받아 조종당하는 Windows PC로 옮겨 실행하세요. 이 PC에서 실행하면 이 PC의 클립보드를 읽게 됩니다.

대상 Windows 도우미 받기

대상 PC의 PowerShell에서 실행합니다.
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\KVM-Windows-Clipboard.ps1

대상 Windows가 Pi와 네트워크로 통신할 수 있어야 합니다. 도우미 창은 최소화해 두세요. KVM 제어 중 Ctrl+C로 복사하면 이 PC 클립보드로 가져옵니다. Ctrl+Alt+Shift로 제어를 해제한 뒤 이 PC에서 Ctrl+V로 붙여 넣으세요. 텍스트 최대 64 KiB를 지원하며 복사 요청이 있을 때만 읽습니다.

대상 기기에 텍스트 입력

대상의 입력할 곳을 먼저 선택하고 영문 상태·Caps Lock 꺼짐으로 준비하세요. ‘|’가 ‘~’로 입력되면 UK 배열을 선택하세요. 한글은 대상의 두벌식 입력기가 필요하며 실제 한/영키는 대상 OS 설정에 따릅니다. 줄바꿈은 Enter, 탭은 Tab으로 입력되며 최대 2,000자입니다. Ctrl+Alt+Shift 또는 ‘입력 중지’로 멈출 수 있습니다.
