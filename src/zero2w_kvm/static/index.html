대상 컴퓨터 USB 연결 대기

Pi의 USB 포트(HDMI에 가까운 쪽)를 대상 컴퓨터에 데이터 케이블로 연결하고 컴퓨터를 켜세요. PWR IN은 전원용입니다. HDMI 연결은 키보드·마우스 입력을 전달하지 않습니다. 장치가 인식되면 제어 버튼이 활성화됩니다.

대상 기기의 입력할 곳을 먼저 선택하고, 영문 입력 상태·Caps Lock 꺼짐으로 준비한 뒤 대상의 실제 키보드 배열을 선택하세요. ‘|’가 ‘~’로 입력된다면 UK 배열을 확인하세요. 한글은 한/영 전환이 동작하는 두벌식 입력기를 선택하고 영문 상태에서 시작해야 합니다. 줄바꿈은 Enter, 탭은 Tab 키로 입력됩니다. 최대 2,000자이며 이모지는 지원하지 않습니다. Esc 또는 ‘입력 중지’로 멈출 수 있습니다.
