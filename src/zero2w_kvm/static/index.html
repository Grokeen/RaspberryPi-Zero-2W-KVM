입력 컨트롤

제어 해제·입력 중지: Ctrl+Alt+Shift를 함께 누르세요. 제어 시작 시 전체 화면과 키보드 잠금을 요청합니다. Esc를 길게 누르면 브라우저 비상 해제가 동작합니다. Ctrl+Alt+Del·Win+L 등 이 PC에서 가로채는 키는 아래 직접 전송을 사용하세요. Fn처럼 OS가 전달하지 않는 키는 물리 입력으로 받을 수 없습니다.

제어 대기 · 시작하면 전체 화면과 키보드 잠금을 요청합니다.

대상 Windows에서 한국어 Microsoft IME를 선택하세요. 오른쪽 Alt로 안 바뀌면 실제 키보드 설정에 맞는 전환키를 선택하세요.

브라우저가 가로채는 단축키도 USB 키보드로 대상에 보냅니다. 이 PC의 창 전환이나 잠금은 실행하지 않습니다. 동작은 대상 Windows 버전·설정·현재 앱에 따릅니다.

대상 Windows 도우미 연결 대기

최초 한 번, 아래 실행 묶음을 받아 Pi USB 키보드가 연결된 조종당하는 Windows PC로 옮기세요. 현재 조종하는 PC에서 실행하면 안 됩니다.

대상 Windows 실행 묶음 받기

기존 도우미 창을 닫고 대상 PC에 Pi USB 케이블을 연결한 뒤 압축을 풀어 Install-KVM-Clipboard.cmd를 한 번 실행하세요. 이후 USB 재연결과 Windows 로그인 시 자동으로 동작합니다. 관리자 권한은 필요 없습니다.

설치 없이 쓰려면 Start-KVM-Clipboard.cmd를 실행하고 창을 최소화하세요. 시간초과가 나면 Check-KVM-Clipboard.cmd로 연결을 검사합니다. 자동 실행 해제는 Uninstall-KVM-Clipboard.cmd입니다.

PowerShell 스크립트만 받기

대상 Windows가 Pi와 네트워크로 통신할 수 있어야 합니다. ‘대상 Windows 도우미 연결됨’ 표시 후 KVM 제어 중 Ctrl+C로 복사하면 이 PC 클립보드로 가져옵니다. Ctrl+Alt+Shift로 제어를 해제한 뒤 이 PC에서 Ctrl+V로 붙여 넣으세요. 텍스트 최대 64 KiB를 지원하며 복사 요청이 있을 때만 읽습니다.

대상 기기에 텍스트 입력

대상의 입력할 곳을 먼저 선택하고 영문 상태·Caps Lock 꺼짐으로 준비하세요. 전송 후에는 다른 창·탭에서 작업하거나 이 탭을 닫아도 Pi가 계속 입력합니다. 다시 열면 진행 상태를 확인할 수 있습니다. ‘입력 중지’ 또는 KVM 창에서 Ctrl+Alt+Shift로 멈출 수 있으며 로그아웃해도 중지됩니다. 대상의 두벌식 입력기와 올바른 US/UK 배열을 선택하세요. 줄바꿈은 Enter, 탭은 Tab으로 입력되며 최대 2,000자입니다.
